## 📁 Структура проекта
- `index.html` - Главная страница (вход + выбор проекта)
- `music.html` - Музыкальный проект
- `diary.html` - Творческий дневник
- `images/` - Фото для дневника
- `tracks/` - MP3 треки
- `cover/` - Обложки треков

## 🚀 Запуск
1. Загрузи все файлы на GitHub
2. Включи GitHub Pages в Settings
3. Сайт будет доступен по ссылке: `https://твой-ник.github.io/evgenii-ai/`

##  Как добавить фото в дневник
1. Загрузи фото в папку `images/`
2. Открой файл на GitHub → нажми **Raw**
3. Скопируй ссылку
4. В админке дневника вставь ссылку в поле "Ссылка на фото"

## 🎵 Как добавить трек
1. Загрузи MP3 в папку `tracks/`
2. Загрузи обложку в папку `cover/`
3. В `music.html` найди массив `allTracks` и добавь новый трек
